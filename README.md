# personal-ops-site

Static policy pages for Personal Ops, deployed at https://personal-ops-site.netlify.app/

- [Privacy Policy](https://personal-ops-site.netlify.app/privacy/)
- [Terms & Conditions](https://personal-ops-site.netlify.app/terms/)

These pages exist to satisfy Twilio's A2P 10DLC registration requirements.
They have no connection to the Personal Ops Rails application or its secrets.
